# Security Policy

## Supported Versions

The following versions of ``qlbm`` are currently supported

| Version              | Supported          | Python Requirement | Backend Requirement   |
| -------------------- | ------------------ |------------------  |-----------------------|
| `main` (unreleased)  | :white_check_mark: | >=3.12             | OpenQARP >= 0.1.1     |
| 0.0.6                | :white_check_mark: | >=3.12             | Qiskit >= 2.0.0       |
| 0.0.5                | :white_check_mark: | >=3.12             | Qiskit >= 2.0.0       |
| <0.0.5               | :x:                | >=3.8              | Qiskit >= 1.0.0, <1.3 |

## Reporting a Vulnerability

To report a security vulnerability, you can contact `qcfd-EWI@tudelft.nl`. Please describe your vulnerability in detail, and include the exact version of Python, `qlbm`, and the quantum backend (`openqarp`, or `qiskit` for releases up to 0.0.6) that are affected.
